# AI简历-JD智能匹配求职分析Agent
## 项目简介
本项目依托 **LangGraph** 搭建多节点大模型工作流，打造一站式求职分析工具。用户上传PDF简历、粘贴岗位JD后，系统自动完成简历文本解析、岗位核心技能抽取、简历适配度量化打分、技能短板排查，并结合薄弱点生成专属面试题库，最终整合输出完整结构化求职分析报告；基于Streamlit搭建轻量化网页交互端，操作便捷，适用于简历优化自查、求职适配评估与面试备考，完整落地大模型任务编排、工具调用与LLM应用工程化流程。

## 技术栈
- 后端核心：Python、LangGraph（流程编排）、LangChain、大模型API
- 文件解析：PyPDF2（PDF文本提取）
- 前端页面：Streamlit
- 环境配置：python-dotenv
- 开发工具：Anaconda虚拟环境

## 核心功能
1. **简历文本解析**：支持PDF简历上传解析，也可手动粘贴简历文本备用
2. **JD技能抽取**：自动拆解招聘需求，提取岗位必备技术栈与任职要求
3. **简历适配打分**：量化简历与岗位匹配总分，区分已掌握技能、欠缺技能
4. **定制面试题生成**：围绕技能缺口生成针对性面试题目
5. **结构化报告汇总**：整合全部数据，排版输出求职分析完整报告

## 快速部署运行
### 1. 环境安装
创建虚拟环境后，安装所需依赖：
```bash
pip install streamlit langgraph langchain langchain-openai pypdf2 python-dotenv
```

### 2. 配置密钥
在项目根目录新建 `.env` 文件，填入大模型接口信息：
```env
LLM_API_KEY=你的大模型密钥
LLM_BASE_URL=接口地址
LLM_MODEL_NAME=模型名称
```

### 3. 启动项目
终端执行命令拉起网页服务：
```bash
streamlit run app.py
```
打开浏览器访问本地地址即可使用系统。

## 使用流程
1. 左侧区域：上传PDF简历文件，系统自动解析简历内容；也可手动粘贴简历文字
2. 右侧区域：粘贴完整招聘岗位JD
3. 点击【开始求职分析】，等待流程运行完毕
4. 页面底部自动生成完整求职分析报告，包含岗位要求、匹配分数、技能差距、面试题库等内容

## 项目亮点
1. 使用LangGraph拆分线性业务节点，流程清晰易迭代维护
2. 轻量化Web界面，无需前端开发基础即可搭建可视化交互平台
3. 全链路自动化：文件解析→技能提取→匹配测算→面试出题→报告整合
4. 结果具象化：量化匹配分数，精准定位求职短板，实用性强

## 适用场景
- 应届生/职场人求职前简历自查优化
- 投递岗位前评估自身适配程度
- 根据岗位需求针对性准备面试
